## About 
This is a frontend application built with **React on Vite**, styled with **Bootstrap**, and utilizing **NVL** for graph visualization. 

## Features  
- ⚡️ **Fast & Optimized**: Powered by Vite for blazing-fast performance.  
- 🎨 **Responsive UI**: Styled with Bootstrap for a sleek, mobile-friendly interface.  
- 📊 **Graph Visualization**: Uses NVL to display data intuitively.  

## Deploying Frontend 
1. Create a .env file
2. Add ```VITE_BACKEND_URL=server_url```. You can run ```backend_server.py``` locally for the ```server_url``` or use a remote deployment
3. Execute ```npm run dev```
